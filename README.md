# Goal Saving Platform

A web-based savings commitment platform for people who want to build disciplined saving habits and reach specific financial goals.

## Tech Stack

- HTML and CSS for responsive pages and interface styling
- JavaScript for form validation, progress updates, and interaction
- PHP for authentication, deposits, and enforcing withdrawal rules
- MySQL for user, goal, and transaction records

## Core Functionality

- Create and track savings goals with target amounts and optional dates.
- Deposit funds into goals and view balances, progress, and transaction history.
- Restrict withdrawals until the goal's configured completion conditions are met.
- Manage active goals and user profile details.

## Project Structure

- `pages/` - HTML pages
- `styles/` - CSS stylesheets
